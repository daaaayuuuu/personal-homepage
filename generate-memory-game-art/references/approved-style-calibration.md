# 已验收最终风格校准

`STYLE.17` 与 `STYLE.18` 是用户确认满意的最终输出。每次生图都读取本文件，并在查看全部 `18` 张独立参考图后，用这两张图校准完成度；它们只控制画风与交互结构，不控制新任务中的真人身份或具体剧情。

## 共同完成度

- 纸面保持冷白 `#FBFDF8`；浅蓝 `#D8EFF5` 形成窗、面板或局部背景块。暖桃色只放在有清楚边界的桌面或道具内；黄色只作 Emoji、灯泡、食物等小面积点色，不得覆盖全图。
- 人物使用半身或中近景，脸高不小于逻辑 `40px`。钴蓝外轮廓在 25% 缩略图中仍连续清楚，约为五官、发丝与衣褶内部线的 `2` 倍。
- 五官克制：点状眼睛、单折鼻、单线嘴；无眼睑、睫毛、虹膜高光、皮肤阴影和腮红塑形。头发是连续深靛色块，只留少量内部线。
- 背景只保留 `2–3` 个地点符号。使用平面重叠，不搭建完整透视，不加摄影景深、柔光或精修材质。
- 道具和 UI 使用粗钴蓝线、平涂、轻微歪斜、错版和不完全闭合路径；禁止完美椭圆、均匀圆角、严格居中与机械等距。

## 已验收描边标尺

- `STYLE.17 / STYLE.18` 对描边粗细拥有最高优先级；早期参考图或通用“粗线插画”表述与下列层级冲突时，以这两张最终图为准。
- 逻辑 `360×640px`：人物外轮廓 `4.8±0.4px`，五官/发丝/衣褶 `2.3±0.2px`，食物/道具/普通 UI 控件 `3.8±0.3px`，大 UI 外框与主场景分隔线 `5.2±0.4px`，提示虚线 `2.8±0.2px`。
- `1080×1920px`：对应 `14.4±1.2px / 6.9±0.6px / 11.4±0.9px / 15.6±1.2px / 8.4±0.6px`。生成其他尺寸时按画布宽度同比缩放。
- 脸、下颌、耳朵、颈肩、手臂、手掌、头发外缘、眼镜外框和衣服外缘必须保持人物外轮廓档；不得在面部或手部附近自动收成精细细线。
- 大 UI 外框和主分隔线允许比人物外轮廓粗 `5%–15%`；食物、餐盘、Emoji 按钮和普通卡片边框保持中档；背景窗格、植物内部线和装饰纹样使用内部线档或更轻，不得抢焦点。
- 禁止全图使用同一线宽。若人物轮廓、五官、餐盘和 UI 外框看起来等粗，或任何主轮廓在 25% 缩略图中局部断裂，判定为描边层级失败并自动重试。

## 人物身份校准

- 判断头发长度时先追踪从头顶到最远可见发梢的连续剪影，再判断脸侧层次、刘海和遮挡。脸侧短层次不能把越肩长发误判成短波波头。
- 身份参考图与已验收风格图分工明确：身份图决定脸型、发型、眼镜、肤色、体型和服装；`STYLE.17 / STYLE.18` 只决定转译方式。
- 同一对人物连续出图时，优先把用户最近确认满意的成图作为一个风格与角色一致性参考；它不能替代原始人物身份图。

## 服装纹样转译

- 只保留底色、纹样类别和主色关系，不逐像素复制，不生成无缝贴图。
- 小花、圆点等微型纹样默认使用 `8–18` 个不规则手绘图案，覆盖可见服装面积 `10%–25%`；大面积纯底色必须比纹样更先被看见。
- 图案大小、角度与间距不同，不排成行列或网格。单个图案用 `2–5` 个点或不闭合短笔概括，颜色对比低于人物主轮廓。
- 纹样在领口、袖口、衣服边缘、头发、手臂和道具遮挡处自然截断；跨遮挡连续、同尺寸重复、等距满铺或过高对比均判为贴图感失败。

## 吃饭场景校准

- 优先提交 `STYLE.17`。使用上方双人半身、下方轻微俯视桌面；食物成为视觉和交互焦点。
- 若用户未指定数量，默认 `5` 份彼此分离的食物，单份 `56–88px`、间距 `16–24px`、热区至少 `48×48px`。不得增加会被误认为点击目标的额外食物。
- `hint` 状态只给一个食物加断续提示环；底部进度点数量必须与食物数量相同。点击一份后该份食物消失，全部消失后通关。

## Emoji 聊天场景校准

- 优先提交 `STYLE.18`。上方人物叙事区与下方浅蓝行动面板形成清楚层级，人物和 UI 不互相挤压。
- 若用户未指定，默认 `4` 枚 Emoji 候选、单枚 `48×48px`、热区 `56×56px`、间距至少 `12px`；只给当前建议项加断续提示环。
- 聊天气泡不用文字，使用头像与 Emoji 组合；头像也必须保留发型剪影、眼镜等身份锚点。默认 `3` 个进度点表示三轮对话。

## 验收

以下任一出现即自动重试：全局偏黄、人物轮廓偏细、半日漫脸、头发长度误判、眼镜丢失、服装纹样像贴图、背景过满、交互目标粘连、提示环不唯一、进度点与目标数量不一致、UI 过度规整。
