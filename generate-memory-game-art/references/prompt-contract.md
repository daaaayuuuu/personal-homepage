## 输入变量

### 必填

- `{{scene_description}}`：用户的自然语言场景描述。保留人物、动作、地点、时间、物件、数量、方向与叙事目的。

### 可选

- `{{character_description}}`：人物外观、服装、身份差异。
- `{{character_reference}}`：人物参考图或已确认角色设定；有值时必须生成左右分离的人物身份卡。
- `{{character_reference_mode}}`：`PHOTO_TO_GAME_ART` 或 `IDENTITY_IN_NEW_SCENE`。
- `{{character_identity_left}}`：参考图左侧人物的完整身份卡和 `4–6` 个身份锚点。
- `{{character_identity_right}}`：参考图右侧人物的完整身份卡和 `4–6` 个身份锚点。
- `{{identity_invariants}}`：人数、左右映射、不可交换特征、年龄与美化限制。
- `{{relationship}}`：初识、暧昧、情侣、伴侣。
- `{{action}}`：核心动作。
- `{{environment}}`：地点、季节、天气与室内外元素。
- `{{key_props}}`：记忆锚点和可交互物件及数量。
- `{{emotion}}`：心动、轻松、亲密、惊喜、期待。
- `{{interaction_mechanic}}`：点击、长按、拖拽、拼合、擦除、密码或拆封。
- `{{interaction_state}}`：默认 `idle`；也可为 `hint`、`pressed`、`dragging`、`near-target`、`success`、`incorrect`、`locked`。
- `{{composition}}`：景别、人物位置、画面分层与视角。
- `{{background_mode}}`：从 `BACKGROUND.PAPER_STAGE / BACKGROUND.COLOR_PANEL / BACKGROUND.FULL_SCENE / BACKGROUND.COLLAGE_MAP` 中选择一个。
- `{{palette_mode}}`：从 `PALETTE.PAPER_STAGE / PALETTE.COLOR_PANEL / PALETTE.FULL_SCENE / PALETTE.MONO_MEMORY` 中选择一个。
- `{{time_lighting}}`：晨光、午后、黄昏或夜间室内灯光。
- `{{aspect_ratio}}`：默认 `9:16`。
- `{{resolution}}`：默认 `1080×1920px`。
- `{{output_type}}`：默认完整场景图，也可为背景层、人物层、道具层或连续画面之一。

未提供的变量按场景推断，不要逐项追问。

## 人物参考图分支

存在人物参考图时，先完整读取 `references/character-identity.md`，查看原图并填写两张位置绑定的身份卡。人物参考图与固定的 `18` 张风格参考图必须作为不同角色输入：前者只控制真人身份，后者只控制画风。参考图质量不足以区分两人时必须先补图，不得自动猜测。

## 组件选择

按场景只选一个主配方：

| 场景语义 | 主配方 |
|---|---|
| emoji、聊天、拼句、组合对话 | `PATTERN.EMOJI_DIALOGUE` |
| 吃饭、分享食物、逐个点击 | `PATTERN.EAT_TOGETHER` |
| 牵手、靠近、试探、长按 | `PATTERN.TENTATIVE_TOUCH` |
| 收拾、装箱、拖入、照片甩出 | `PATTERN.PACK_AND_REVEAL` |
| 密码、情书、礼物、最终揭晓 | `PATTERN.UNLOCK_ENDING` |
| 其他 | 从 `UI.TAP_TARGET / UI.DRAG_ITEM / UI.HOLD_TARGET / UI.WIPE_MASK / UI.REVEAL` 中选择最少组件组合 |

## 优先级

1. 用户本次明确要求。
2. 人物参考图中的身份、人数、左右映射和可辨识特征。
3. `PHOTO_TO_GAME_ART` 中的原图姿态、表情和亲密关系；`IDENTITY_IN_NEW_SCENE` 中用户明确的新动作与构图。
4. 连续画面中的人物一致性。
5. 场景事实、数量和方向。
6. 数值化组件系统。
7. 自动推断。

## 短版生图提示词模板

先在内部完成全量设计规格，再用下列模板压缩成中文 `900–1800` 字的高优先级生图提示词。输出时删除空变量、替换所有花括号并写出真实组件；不重复组件系统全文，不把静态画面看不到的动画时长全部塞入提示词。必须保留人物身份、数量与左右关系、静态构图、核心交互状态、四档线宽层级、平涂低细节和反 AI 排除项。

```text
创作一张原创的二维粗线手绘互动叙事游戏画面。固定风格参考只控制粗钴蓝线、成年人物简化、平涂错版、低细节背景、笨拙道具和手绘 UI；不复制其中的角色、文字、镜头或布局，忽略截图黑边、字幕、主页图标和水印。人物粗轮廓优先于精细刻画，画面要像人工绘制的互动绘本，不像干净商业 AI 插画。

【人物参考图身份约束】
模式：{{character_reference_mode}}。
输入角色：人物参考图只控制身份，所选风格图只控制画风。
CHARACTER.LEFT：{{character_identity_left}}。
CHARACTER.RIGHT：{{character_identity_right}}。
映射不变量：{{identity_invariants}}。
不得交换两人的脸型、五官轮廓、发型、发色、肤色、体型、服装或显著标记；不得过度美化、换脸、改变年龄或生成相似的通用卡通脸。

【场景】
{{scene_description}}。人物：{{character_description}}；关系与情绪：{{relationship}}、{{emotion}}；动作：{{action}}；环境：{{environment}}；关键道具：{{key_props}}，数量和位置准确；时间：{{time_lighting}}。只保留 `2–3` 个地点符号，不搭建完整摄影透视，不让背景抢过人物和交互物。

【构图与交互】
逻辑画布 `360×640px`，输出 `1080×1920px`，9:16；背景模式 {{background_mode}}，色彩模式 {{palette_mode}}；构图 {{composition}}。主配方 {{selected_pattern}}；可见组件 {{selected_components_with_dimensions}}；当前状态 {{interaction_state}}，以静态画面清楚表现 {{interaction_mechanic}}。所有可操作物热区不小于 `48×48px`，组件可见间距不小于 `12px`。

【人物简化】
成年人物 `6.0–7.0` 头身；人物辨识为核心时脸高不小于 `40px`。眼睛只用 `1–3×3–5px` 点或短线，鼻子单折线，嘴巴单线或一个露齿白块，脸部 `65%–82%` 留白。头发是一个深色块，仅 `2–6` 条内部线；上衣衣褶 `1–4` 条，裤装 `1–3` 条；手只画动作所需轮廓和 `0–2` 条分指线。禁止眼睑、双眼皮、睫毛、皮肤阴影、发丝高光和精修手部。
若服装有小花、圆点等微型纹样，只保留底色、纹样类型和主色关系；使用 `8–18` 个不规则手绘图案、覆盖 `10%–25%`，在衣缘与头发、手臂、道具遮挡处截断，禁止等距平铺和同尺寸重复。

【粗线与平涂】
以 `STYLE.17 / STYLE.18` 为描边最高优先级标尺。逻辑画布线宽：人物外轮廓 `4.8px±0.4px`，五官/发丝/衣褶 `2.3px±0.2px`，食物/道具/普通控件 `3.8px±0.3px`，大 UI 外框与主场景分隔线 `5.2px±0.4px`，提示虚线 `2.8px±0.2px`；高清输出分别为 `14.4px±1.2px`、`6.9px±0.6px`、`11.4px±0.9px`、`15.6px±1.2px`、`8.4px±0.6px`。人物外轮廓约为内部线 `1.9–2.3` 倍；脸、下颌、耳朵、颈肩、手臂、手掌、头发外缘、眼镜外框和衣服外缘全部保持人物粗线。大 UI 外框可与人物等重或粗 `5%–15%`，背景结构线必须更轻，禁止全图统一线宽。主线钴蓝 `#202796`，深色块 `#252662`，禁止纯黑。路径每 `12–24px` 偏移 `0.8–1.6px`，色块与线错位 `1–3px`，边缘保留干刷缺口；只用平涂，不用渐变、柔光或立体塑形。

【颜色、背景与道具】
空白纸面 `#FBFDF8`，局部浅蓝 `#D8EFF5`，只建立 `1` 个主色关系和最多 `2` 个辅助色。黄色必须有明确边界，禁止全局黄滤镜。普通背景细节占全画布 `5%–15%`。关键道具占 `15%–35%`，外形保留 `2–5px` 不对称和错位，只用 `1` 个主色、最多 `1` 个辅助色和 `1–5` 条内部线；禁止完美圆、完美圆角、真实反光和完整透视。

【输出与排除】
输出 {{output_type}}，1080×1920px。图片内不生成文字、字幕、水印或 logo。排除：身份交换、通用卡通脸、过度美化、半日漫精致脸、双眼皮睫毛、皮肤阴影、发丝高光、精修手部、细弱人物轮廓、光滑商业矢量线、柔和渐变、完整室内透视、高密度背景、完美几何道具、严格居中等距 UI、3D、厚涂、电影光效、Q 版、错误肢体、黑边、字幕、主页图标、乱码和无关人物。以上身份、数量、粗线和平涂关系均为硬约束。
```

## 组件参数展开规则

- `{{selected_pattern}}` 必须替换为真实配方 ID。
- 内部设计规格必须列出全部组件尺寸、坐标、状态和动画；`{{selected_components_with_dimensions}}` 在生图提示词中只保留当前静态画面可见的核心组件、尺寸、数量和相对位置。
- `{{interaction_state}}` 必须写清 `hint / pressed / dragging / success` 等当前可见状态；动画时长仅保留会改变静态姿态、缩放或透明度的值。
- `{{background_mode}}` 与 `{{palette_mode}}` 必须替换为真实模式 ID；生图提示词只展开主要纸面、场景板和点色面积关系，避免重复整个色彩表。
- 有人物参考图时必须展开 `{{character_reference_mode}}`、左右身份卡和映射不变量；没有人物参考图时删除整个“人物参考图身份约束”段落。
- 若用户只要静态画面，也要把交互前一刻或完成一刻的状态参数写进提示词。
- 用户指定非 `9:16` 画幅时，用 `S=输出宽度÷360` 换算尺寸，并在提示词中写出换算后的数字。
- 短版提示词超过中文 `1800` 字时，优先删除重复的通用禁令、不可见动画参数和次要坐标；不得删除身份锚点、人物线宽、平涂低细节、关键道具数量与当前交互状态。

## 展示与生图顺序

1. 输出 `### 完整生图提示词`。
2. 在一个代码块中展示补全后的短版高优先级提示词；不得留下空变量。
3. 立即把同一份提示词原样提交给图像生成工具。
4. 先逐张检查 `references/style-images/` 中全部 `18` 张原图，再按 `references/style-reference-index.md` 选择与本场景最相关的独立原图直接提交：无人像参考时最多 `5` 张；有 `1` 张身份参考时最多 `4` 张风格图；另有布局参考时最多 `3` 张风格图。聊天优先 `STYLE.18`，吃饭优先 `STYLE.17`；不得拼版、删除或覆盖固定原图。
5. 只有用户明确要求“只要提示词”“暂不生图”或“确认后生成”时才停止。
6. 自动重试前必须先展示修订后的完整提示词。

## 输出检查

- 内部设计规格已记录画布、全部组件、坐标、状态和动画；短版提示词已保留人物外轮廓、内部线、食物/道具/普通控件、大 UI 外框/主分隔线四档线宽，以及人物简化、背景模式、色彩模式、关键组件尺寸、数量和当前可见状态。
- 没有空变量、互相矛盾的参数或大段重复禁令；短版提示词没有因压缩而丢失身份锚点和交互事实。
- 画面动作、人物身份、道具数量、左右关系和交互目标正确。
- 有人物参考图时，逐人通过 `references/character-identity.md` 的身份锚点验收；发型轮廓、发色、脸型和显著标记必须匹配，每人还需至少匹配另外 `4` 项，不得用服装相同替代人物相似。
- 两人未交换特征、未改变年龄、未过度美化，也未生成相似的通用卡通脸。
- 实际成图符合所选 `BACKGROUND` 与 `PALETTE` 模式；空白纸面接近 `#FBFDF8`，没有全局黄滤镜。若使用大面积黄色，它必须具有清楚的场景板、桌面或道具边界。
- 在 `25%` 缩略预览下，人物主外轮廓、大 UI 外框、食物与主要道具轮廓都连续清楚；人物外轮廓约为内部五官、发丝与衣褶的 `2` 倍，大 UI 外框不细于人物轮廓，食物/普通控件不退化为内部线。脸、下颌、耳朵、颈肩、手臂、手掌、头发外缘、眼镜外框任一变细，或全图线宽趋同，都判为失败并自动重试。
- 人物脸部没有眼睑睫毛、皮肤明暗和高光发丝；头发是整体色块，衣褶和手部线条数量受控。出现半日漫精致脸或顺滑商业插画渲染即判为失败。
- 单独核对整体头发长度和服装纹样：长发不得因脸侧层次被画短；微型纹样不得等距满铺、同尺寸重复或穿过遮挡物。
- 背景只保留 `2–3` 个地点符号，没有完整摄影透视或高密度结构；道具使用钴蓝粗轮廓、平涂、不对称外形和 `1–5` 条内部线。道具完美几何或 UI 严格居中等距即判为失败。
- 已逐张检查全部 `18` 张固定风格原图，并按输入上限提交最相关的独立参考；成图没有复制其中的角色、镜头、地图、文字，也没有带入截图黑边、字幕、播放器元素、主页图标、品牌名或水印。
- 展示给用户的提示词与提交给图像工具的提示词完全一致。
