# 留刻数值化画面与交互组件系统

本文件是可执行设计规范，不是风格形容词清单。所有 `px` 均以 `360×640px` 逻辑画布为基准；输出 `1080×1920px` 时全部尺寸乘以 `3`。

## 1. 坐标与缩放

### 1.1 基准画布

| Token | 数值 |
|---|---:|
| `canvas.logical` | `360×640px` |
| `canvas.export` | `1080×1920px` |
| `canvas.scale` | `3×` |
| `safe.left/right` | `20px` |
| `safe.top` | `24px` |
| `safe.bottom` | `24px` |
| `content.width` | `320px` |
| `grid.base` | `4px` |

非 `9:16` 画幅使用 `S = 输出宽度 ÷ 360`；所有尺寸乘以 `S`，线宽最小不得低于 `1px`。

### 1.2 层级

| 层级 | z 值 | 内容 |
|---|---:|---|
| `L0` | `0` | 纸面背景 |
| `L1` | `10` | 地点提示与大色块 |
| `L2` | `20` | 人物与主要家具 |
| `L3` | `30` | 关键道具 |
| `L4` | `40` | 可交互组件与热区 |
| `L5` | `50` | 成功、错误和引导反馈 |

## 2. 基础 Token

### 2.1 间距

`space.1=4px`、`space.2=8px`、`space.3=12px`、`space.4=16px`、`space.5=24px`、`space.6=32px`、`space.7=48px`。

同级组件默认间距 `12px`；画面区与操作区间距 `24px`；连续漫画格间距 `12px`。

### 2.2 圆角

| Token | 数值 | 用途 |
|---|---:|---|
| `radius.s` | `6px` | 数字格、照片角 |
| `radius.m` | `12px` | 卡片、按钮 |
| `radius.l` | `20px` | 操作面板 |
| `radius.pill` | `999px` | 对话条、进度条 |

圆角路径允许 `±1px` 手绘偏差；四角不得完全一致。

### 2.3 颜色

| `paper.white` | `#FBFDF8` | 默认空白纸面与呼吸区 |
| `paper.ivory` | `#FBEFC8` | 局部米白场景板、地图纸和暖色纸面 |
| `panel.pale-blue` | `#D8EFF5` | 道具面板、工作台和冷色背景块 |
| `panel.blue-gray` | `#A9B6C6` | 室内背景、冷灰阴影与次级面板 |
| `ink.cobalt` | `#202796` | 人物、道具、卡片和 UI 的默认主轮廓 |
| `ink.indigo` | `#252662` | 头发、深色服装、深阴影和次级深线 |
| `ink.graphite` | `#3F4650` | 极少量中性机械物或时钟线，不得替代主轮廓 |
| `accent.yellow` | `#FBB303` | 黄色桌面、对话块、服装和核心情绪色 |
| `accent.lemon` | `#FEE548` | 高亮音符、局部食物和小面积亮点 |
| `accent.cyan` | `#15B1E3` | 服装、拼图、按钮和高饱和背景块 |
| `accent.aqua` | `#71C9D9` | 图案墙、浅青面板和次级冷色块 |

| `accent.sage` | `#A9B51F` | 地图、公园、植物和低饱和点色 |
| `accent.warm-brown` | `#DAA05A` | 深肤色、烘焙食物和单色记忆层级 |
| `state.error` | `#D95B62` | 错误反馈，面积不超过 `3%` |

每张图必须选择一个色彩模式：

| 模式 | 画布面积关系 | 适用画面 |
|---|---|---|
| `PALETTE.PAPER_STAGE` | `paper.white 55%–80%`；点色合计 `10%–30%` | 浮动画框、拼图、章节页、普通回忆 |
| `PALETTE.COLOR_PANEL` | 纸面 `30%–55%`；一个彩色场景板 `25%–55%`；其余点色 `8%–20%` | 吃饭、工作室、做饭、对话 |
| `PALETTE.FULL_SCENE` | 纸面 `5%–25%`；`2–3` 个大平涂色块合计 `55%–80%` | 拥抱、卧室、情绪高潮和近景 |
| `PALETTE.MONO_MEMORY` | 单一主色的 `3` 个明度层级合计 `55%–75%`；纸面 `20%–40%`；异色点缀不超过 `5%` | 演出、回想、时间跳转 |

- 单图使用 `1` 个主色关系和最多 `2` 个辅助色关系；服装和肤色不计入交互点色数量。
- 黄色可以占全画布 `5%–25%`，或占单个彩色场景板 `35%–65%`，但必须限定在桌面、场景板、对话块、服装或道具内；不得给纸面、人物和背景同时叠加统一黄褐滤镜。
- 暖光用平涂色块表达，不使用照片式白平衡、渐变光晕或全局滤镜。
- 阴影默认关闭。确需分离人物或道具时，使用 `panel.blue-gray` 或低饱和冷灰，透明度 `25%–45%`、硬边偏移 `2–6px`、模糊 `0px`；单屏最多 `2` 块阴影。

### 2.4 后期文字容器

图片内不直接生成文字。若必须设计容器，按以下值预留：标题 `20px/28px`、正文 `14px/20px`、提示 `12px/16px`；字体使用 Noto Sans SC，字重 `400/600`；文字区左右内边距 `16px`。

## 3. 线条与材质

### 3.1 线宽

| Token | 逻辑画布 | `1080×1920px` 输出 |
|---|---:|---:|
| `stroke.character.outer` | `4.8px ± 0.4px` | `14.4px ± 1.2px` |
| `stroke.character.inner` | `2.3px ± 0.2px` | `6.9px ± 0.6px` |
| `stroke.scene.major` | `5.2px ± 0.4px` | `15.6px ± 1.2px` |
| `stroke.prop.outer` | `3.8px ± 0.3px` | `11.4px ± 0.9px` |
| `stroke.ui.frame` | `5.2px ± 0.4px` | `15.6px ± 1.2px` |
| `stroke.ui.control` | `3.8px ± 0.3px` | `11.4px ± 0.9px` |
| `stroke.hint` | `2.8px ± 0.2px` | `8.4px ± 0.6px` |

提示词必须同时写出逻辑画布和高清输出两套线宽，不能只写逻辑值。主轮廓默认使用 `ink.cobalt`，深色发块和局部暗线使用 `ink.indigo`，禁止纯黑主轮廓。若生成模型不稳定理解绝对像素，追加相对门槛：人物主外轮廓约占画布宽度 `1.22%–1.44%`，内部结构线约占 `0.58%–0.69%`，食物/道具/普通控件约占 `0.97%–1.14%`，大 UI 外框和主场景分隔线约占 `1.33%–1.56%`。人物主外轮廓与内部线的视觉粗细比必须为 `1.9:1–2.3:1`；脸、下颌、耳朵、颈肩、手臂、手掌、头发外缘、眼镜外框和衣服外缘不得降为内部线宽。大 UI 外框和主分隔线可比人物外轮廓粗 `5%–15%`，普通背景结构线不得抢重。

### 3.2 手绘扰动

- 每段连续路径每隔 `12–24px` 产生一次 `0.8–1.6px` 的横向偏移。
- 单条路径线宽变化量为基准线宽的 `18%–28%`。
- 只允许在发梢、衣角、卡片角和家具转折处出现占主轮廓 `0%–8%` 的短复描线；使用同色 `35%–55%` 不透明度、偏移 `0.8–1.6px`，不得形成整圈重影或铅笔草稿感。
- 路径端点允许超出交点 `1–3px`；禁止全部端点精确闭合。
- 直线长度超过 `80px` 时必须拆为 `3–5` 个轻微偏折段，单段角度偏差 `0.3°–0.8°`。
- 空白纸面的颗粒大小 `0.6–1.2px`、不透明度 `2%–4%`、覆盖率 `5%–15%`，整体保持干净。
- 彩色色块内部允许 `8%–20%` 面积出现同色系干刷纹、稀疏排线或颗粒；纹理明度差为 `6%–14%`，不得变成照片噪点或厚涂笔触。
- 色块边缘与轮廓错位 `1.0–3.0px`；大色块边缘允许 `1–5px` 的干刷缺口，不得使用完美矢量贴合。
- 人物、道具和 UI 均禁止平滑商业矢量感：不得使用完美贝塞尔曲线、严格镜像对称、均匀圆角、柔和渐变塑形或精修高光。

## 4. 人物组件

### 4.1 比例

| 参数 | 数值 |
|---|---:|
| 成年人物头身比 | `1:6.0–1:7.0` |
| 肩宽 | `1.5–2.2` 个头宽，按真人体型分别保留 |
| 手掌长度 | `0.70–0.90` 个脸长 |
| 双人默认身高差 | `4%–12%` |
| 双人日常距离 | `32–72px` |
| 双人试探距离 | `12–28px` |
| 双人亲密重叠 | 人物轮廓重叠 `6%–18%` |

全身构图人物高度 `220–320px`；半身或近景人物高度 `260–420px`；远景人物高度 `96–160px`。人物使用自然偏修长但不时装化的成人比例，四肢可以简化但关节方向必须可信；不得采用 `1:4` 以下 Q 版比例或 `1:8` 以上时装比例。

### 4.2 五官

- 眼睛使用 `1.6–2.2px` 线宽的点或短线，尺寸 `1–3px × 3–5px`。
- 双眼间距为单眼宽度的 `1.0–1.4` 倍。
- 鼻子使用 `3–7px` 单折线、短弧或不绘制；按真人鼻梁和鼻尖差异选择，不使用写实鼻孔明暗。
- 嘴巴使用 `5–10px` 单线或小开口形，嘴角垂直变化不超过 `3px`；露齿只用一个白色块，不逐颗画牙。
- 眉毛使用 `4–10px` 的单线或小色块；保留真人眉形方向，但不画精细毛流。
- 面部无细节区域必须占脸部面积 `65%–82%`。
- 禁止虹膜、高光、彩色瞳孔、双眼皮线、眼睑渲染、长睫毛、鼻翼阴影、皮肤渐变塑形、尖下巴和腮红圆斑；面部只保留识别身份所需的最少线条。

### 4.3 头发与服装

- 头发以 `1` 个 `ink.indigo` 或人物原发色的深色整体色块为主，内部发丝线数量 `2–6` 条；禁止镜面高光、渐变高光、分束亮边和逐根写实发丝。
- 先沿头顶到最远可见发梢判断整体长度，再记录刘海和脸侧层次；越肩连续发块不得因脸侧短层次误记为短发。
- 发梢外轮廓偏移 `1–3px`，相邻发梢夹角 `18°–45°`。
- 单件服装使用 `1` 个主色和最多 `1` 类图案。小花、圆点等微型纹样默认 `8–18` 个、覆盖服装 `10%–25%`，大小、角度和间距不同，并在衣缘与遮挡处截断；条纹可按服装结构放宽，但不得无缝平铺。
- 衣褶线数量：上衣 `1–4` 条，裤装 `1–3` 条；禁止密集动漫式衣褶、布料明暗和贴体渲染。
- 手部在普通动作中用连贯粗轮廓和 `0–2` 条分指线概括；只有握物、触碰和拥抱等关键动作才画清手指方向，不强调指甲、关节纹、掌纹和立体明暗。
- 胡须、体毛和雀斑是身份锚点时，使用 `8–30` 条短点线局部表达；不是身份锚点时不得自动添加。

### 4.4 人物参考图任务

- 分别用 `CHARACTER.LEFT`、`CHARACTER.RIGHT` 绑定参考图中的人物；人数、左右位置、发型、肤色、体型、服装和面部特征不得交换。
- 身份辨识为核心时使用半身或中近景，可见脸高不得小于 `40px`；若原构图无法满足，优先调整景别，不得把人物缩成仅靠服装颜色区分的小人。
- 在眼睛、鼻子和嘴巴的极简尺寸内保留两人的相对差异：脸部长宽比、下颌走向、眉眼角度、鼻部长度、嘴角曲线、耳朵外露度和发型外轮廓。
- 每人选取 `4–6` 个身份锚点，至少包含发型轮廓和脸型；眼镜、胡须、痣、刘海、耳饰等显著标记必须保留。
- 不套用同一张默认脸，不改变年龄，不换脸，不过度美化。人物、场景、道具和 UI 仍共享本文件规定的线宽、手绘扰动和平涂材质。

## 5. 场景画面组件

### 5.1 背景模式

每张图只选一个主背景模式：

| 模式 | 参数 | 适用情况 |
|---|---|---|
| `BACKGROUND.PAPER_STAGE` | 空白纸面 `55%–80%`；浮动画框或人物区 `20%–45%` | 默认回忆页、拼图、章节、拍立得 |
| `BACKGROUND.COLOR_PANEL` | 纸面 `30%–55%`；单个彩色叙事板 `280–320px × 180–420px` | 吃饭、工作、做饭、对话场景 |
| `BACKGROUND.FULL_SCENE` | 彩色场景覆盖 `75%–95%`；只保留 `5%–25%` 呼吸区 | 拥抱、卧室、情绪高潮和亲密近景 |
| `BACKGROUND.COLLAGE_MAP` | 地图或纸张底板 `65%–85%`；卡片 `3–10` 张；重叠面积 `15%–35%` | 路线、地点、记忆集合；仅在内容明确需要时使用 |

- 普通背景只画 `2–3` 个地点符号，细节占全画布 `5%–15%`；室内工作台或局部叙事板内默认不超过 `12%–25%`。
- 只有 `BACKGROUND.COLLAGE_MAP` 可把局部背景细节提高到 `45%–70%`；仍须通过大边框、纸面或主卡片建立焦点。
- 空间采用平面化侧视、轻微俯视或正面构图；只用重叠和高低关系表达空间，不搭建完整一点/两点透视室内，不生成摄影级景深、镜头虚化、体积光或真实材质反射。
- 重复花纹使用小花、圆点、短划线等扁平图形；单个图形 `3–8px`，间距 `12–28px`，覆盖一个明确面板，不铺满所有层级。

### 5.2 道具风格

- 关键交互道具占画布 `15%–35%`，可放入独立的 `panel.pale-blue` 或 `paper.white` 面板；普通陪衬道具每件占 `2%–8%`，数量 `2–5` 个。
- 道具外轮廓使用 `stroke.prop.outer` 与 `ink.cobalt`；形状必须保留 `2–5px` 不对称和错位，同类左右边、圆角和椭圆不得完全一致，禁止完美几何、3D 倒角、写实反光和材质贴图。
- 杯、碗、餐盘、闹钟、台灯、电脑和家具使用 `1` 个主色块、最多 `1` 个辅助色块及 `1–5` 条内部结构线；不得用明暗渐变塑造体积。
- 食物作为核心道具时允许 `12–30` 个受控小细节表示配料、烤痕或颗粒；所有细节必须限制在食物轮廓内，并保持主轮廓在缩略图下最清楚。
- 拍立得和记忆卡使用 `2.4–3.0px` 手绘边框、`-6°–6°` 旋转、`12–28px` 错位；单屏主卡最多 `1` 张，辅助卡最多 `9` 张。
- 交互物与场景物通过尺寸和隔离面板区分，不依赖发光、悬浮玻璃或照片式阴影。

### `SCENE.CANVAS`

- 外框 `360×640px`；必须写明所选 `BACKGROUND` 与 `PALETTE` 模式。
- 主体高度占画布 `48%–70%`，主体中心位于 `y=240–400px`。
- `PAPER_STAGE / COLOR_PANEL` 顶部呼吸区为 `48–115px`；`FULL_SCENE` 顶部呼吸区可降至 `16–48px`。
- 空白纸面使用 `paper.white`；彩色场景板可以使用黄色、青色、浅蓝或单色记忆色，但必须有明确边界，不得覆盖全局黄滤镜。

### `SCENE.PANEL`

- 矩形宽 `280–320px`、高 `180–420px`，位置 `x=20–40px, y=48–160px`；按人物景别和操作区实际展开，不固定为单一尺寸。
- 边框使用 `stroke.scene.major`，内边距 `12px`，圆角 `0–6px`，四边不得完全平直或等粗。
- 单屏最多 `3` 个叙事格；两格高度比例 `1:1` 或 `3:2`；格间距 `12px`。

### `SCENE.CHAPTER`

- 角色小插图高度 `96–132px`，中心 `x=180px`，底部 `y=420–460px`。
- 标题预留区 `220×64px`，中心 `x=180px, y=170–210px`。
- 下一步按钮位于 `x=154px, y=536px`，尺寸 `52×52px`。

### `SCENE.MEMORY_CARD`

- 卡片 `220×280px` 或 `280×220px`；边框使用 `stroke.ui.control`；圆角 `6px`。
- 照片安全区距离卡片边缘 `12px`；照片倾斜角度只允许 `-6°–6°`。
- 普通页面重叠卡片最多 `4` 张，每张错位 `20–36px`；`COLLAGE_MAP` 可用 `5–10` 张，但必须保留 `1` 张最大主卡。

### `SCENE.EMOTION_SHAPE`

- 单个色块宽 `72–180px`、高 `28–96px`，圆角 `20–48px`。
- 单屏数量 `1–4` 个，总面积不超过画布 `18%`。
- 色块与人物轮廓重叠不得超过人物面积 `8%`。

## 6. 通用交互组件

### `UI.NEXT`

- 圆形 `52×52px`，描边使用 `stroke.ui.control`，箭头 `22×18px`。
- 默认底部居中 `x=154px, y=556px`；右下变体 `x=284px, y=556px`。
- 热区 `56×56px`，热区不得超出安全区。

### `UI.ACTION_PANEL`

- 宽 `320px`，高 `120–196px`，位置 `x=20px, y=420–496px`。
- 内边距 `16px`，组件间距 `12px`，边框使用 `stroke.ui.frame`，圆角 `12px`；边框与内部对象允许 `1–3px` 手绘偏移。

### `UI.TAP_TARGET`

- 可见物件最小 `36×36px`，热区最小 `48×48px`。
- 引导环直径为热区的 `1.15×`，描边使用 `stroke.hint`，透明度从 `65%` 到 `0%`。

### `UI.DRAG_ITEM`

- 物件尺寸 `48–96px`；热区在四周增加 `8px`。
- 拖动时提升 `z=45`，缩放 `1.04×`，阴影偏移 `3px 3px`。
- 吸附阈值为目标中心距离 `24px`；吸附时间 `180ms`。

### `UI.SNAP_ZONE`

- 尺寸必须比拖拽物件宽高各增加 `12px`。
- 虚线描边使用 `stroke.ui.control`，线段 `6px`，间隔 `4px`，圆角 `12px`。
- 接近目标 `24px` 时描边透明度从 `45%` 提升至 `100%`。

### `UI.HOLD_TARGET`

- 可见区域 `56×56px`，热区 `64×64px`。
- 环形进度线宽使用 `stroke.ui.control`；完成时长 `700ms`；中断回退 `180ms`。

### `UI.WIPE_MASK`

- 擦除笔刷直径 `32px`；边缘羽化 `2px`。
- 已擦除面积达到 `70%` 判定完成；完成过渡 `320ms`。

### `UI.CODE_INPUT`

- 输入格数量 `4–6` 个；单格 `44×52px`；间距 `8px`；边框使用 `stroke.ui.control`；圆角 `6px`。
- 数字键 `56×48px`；键间距 `8px`；热区 `56×48px`。
- 输入错误水平位移 `±4px`，往返 `3` 次，总时长 `240ms`。

### `UI.REVEAL`

- 被揭晓物件 `240×160px` 或 `220×280px`。
- 遮罩边缘移动距离必须达到组件宽度的 `70%` 才完成。
- 完成后物件缩放 `0.96×→1.04×→1.00×`，总时长 `360ms`。

## 7. 五类场景组件配方

### `PATTERN.EMOJI_DIALOGUE`

- 用户要求“点击”时使用 `SCENE.PANEL + UI.ACTION_PANEL + UI.TAP_TARGET`，点击后 Emoji 进入气泡并触发回应；只有用户明确要求“拖拽/拼合”时才使用 `UI.DRAG_ITEM + UI.SNAP_ZONE`。
- 优先使用 `BACKGROUND.COLOR_PANEL + PALETTE.COLOR_PANEL`，让人物叙事区和操作面板形成清楚上下层级。
- 对话画面区 `320×260px`；对话组合槽 `288×64px`。
- emoji 候选 `48×48px`，热区 `56×56px`，候选间距 `12px`，单屏 `3–5` 个。
- 用户未指定时默认 `4` 个候选与 `3` 个进度点；`hint` 状态只给一个候选加断续提示环。气泡只用头像与 Emoji 组合，不生成对白文字。
- 点击式完成条件：完成指定对话轮次或选中目标 Emoji；拖拽式完成条件：所有槽位占用且顺序正确，吸附阈值 `24px`。

### `PATTERN.EAT_TOGETHER`

- 使用 `SCENE.PANEL + UI.TAP_TARGET`。
- 优先使用 `BACKGROUND.COLOR_PANEL + PALETTE.COLOR_PANEL`；近景亲密时可改为 `BACKGROUND.FULL_SCENE`，但食物道具仍须独立清楚。
- 桌面互动区 `320×220–280px`；食物物件 `56–88px`；物件间距 `16–24px`。
- 用户未指定时默认 `5` 份彼此分离的食物和 `5` 个空心进度点；`hint` 状态只给一个食物加断续提示环，不添加会被误认为目标的额外食物。
- 每次点击缩放 `1.00×→0.94×→1.02×→1.00×`，总时长 `220ms`。
- 完成条件：每次点击后对应食物消失；全部目标食物消失后通关。用户明确指定其他规则时以用户规则为准。

### `PATTERN.TENTATIVE_TOUCH`

- 使用 `SCENE.PANEL + UI.DRAG_ITEM` 或 `UI.HOLD_TARGET`。
- 试探阶段优先 `BACKGROUND.PAPER_STAGE`；完成或拥抱阶段可切换为 `BACKGROUND.FULL_SCENE`。
- 两只手初始边缘距离 `96–140px`；触碰完成距离 `0–8px`。
- 拖动吸附阈值 `20px`；长按完成时长 `700ms`。
- 成功时两只手共同位移 `6px`，人物轮廓重叠增加 `6%–10%`。

### `PATTERN.PACK_AND_REVEAL`

- 使用 `UI.ACTION_PANEL + UI.DRAG_ITEM + UI.SNAP_ZONE + UI.REVEAL`。
- 使用 `BACKGROUND.PAPER_STAGE + PALETTE.PAPER_STAGE`，通过孤立道具和卡片层叠建立重点。
- 行李箱 `280×176px`；可拖物件 `48–84px`；槽位数量 `3–6` 个。
- 放置成功后物件旋转回 `0°`，时间 `180ms`；完成后揭晓卡 `220×280px`。
- 甩出照片的位移 `120–180px`，旋转 `-8°–8°`，时间 `360ms`。

### `PATTERN.UNLOCK_ENDING`

- 使用 `UI.CODE_INPUT + UI.REVEAL + UI.NEXT`。
- 解锁前使用 `BACKGROUND.PAPER_STAGE`，揭晓后可切换为 `BACKGROUND.COLOR_PANEL` 或 `BACKGROUND.FULL_SCENE`。
- 密码区宽 `280px`；输入格 `4–6` 个；礼物或信封 `240×160px`。
- 密码正确后延迟 `160ms`，信封盖旋转 `0°→-115°`，时间 `450ms`。
- 礼物揭晓后保持中心 `x=180px, y=300–360px`，下一步按钮在 `y=556px`。

## 8. 状态与动画

| 状态 | 数值参数 |
|---|---|
| `idle` | 缩放 `1.00×`，透明度 `100%` |
| `hint` | 缩放 `1.00×→1.05×→1.00×`，周期 `900ms` |
| `pressed` | 缩放 `0.96×`，时间 `120ms` |
| `dragging` | 缩放 `1.04×`，旋转 `-2°–2°`，z=`45` |
| `near-target` | 目标描边 `45%→100%`，时间 `120ms` |
| `success` | 缩放 `1.00×→1.08×→1.00×`，时间 `320ms` |
| `incorrect` | 水平位移 `±4px`，往返 `3` 次，时间 `240ms` |
| `locked` | 饱和度 `35%`，透明度 `55%` |
| `disabled` | 透明度 `35%`，禁止引导动画 |

默认缓动：按压 `cubic-bezier(0.2,0,0,1)`；吸附 `cubic-bezier(0.34,1.56,0.64,1)`；揭晓 `cubic-bezier(0.22,1,0.36,1)`。

## 9. 组合与验收规则

1. 每屏只设置 `1` 个主要任务和最多 `1` 个辅助按钮。
2. 主互动组件必须落在 `x=20–340px, y=320–592px` 的拇指可达区。
3. 所有热区不得小于 `48×48px`，热区之间不得小于 `8px`，可见组件之间不得小于 `12px`。
4. 单屏叙事格不得超过 `3` 个，可拖拽物件不得超过 `6` 个；只使用 `1` 个主色关系和最多 `2` 个辅助色关系。
5. 人物、道具和 UI 的主轮廓必须共享 `ink.cobalt` 和同一组手绘扰动参数；`ink.indigo` 只用于头发、深色服装和局部暗线。大 UI 外框与主场景分隔线可比人物外轮廓粗 `5%–15%`；除此之外人物外轮廓必须保持最重，不能被普通背景结构线、装饰或道具内部线抢走。
6. 画面不得出现纯黑 `#000000`、模糊投影、透明玻璃、渐变、发光描边和规整矢量直线。
7. 内部设计规格必须记录所选 `PATTERN`、`BACKGROUND`、`PALETTE`、组件尺寸、人物比例、线宽、抖动、留白、色块面积、道具层级和状态参数；短版生图提示词只保留会改变当前静态画面的核心数值，避免参数稀释风格优先级。
8. 若生成模型无法精确理解像素，仍须在短版提示词保留人物外轮廓、内部线、食物/道具/普通控件、大 UI 外框/主分隔线四档数值及其比例，并追加“按 `STYLE.17 / STYLE.18` 的描边层级，粗轮廓优先于精细刻画”。
9. 在 `25%` 缩略预览下，人物主外轮廓、大 UI 外框、食物与主要道具轮廓必须保持连续清楚；人物外轮廓约为五官、发丝和衣褶的 `2` 倍，大 UI 外框不得细于人物轮廓，食物/普通控件不得退化为内部线。任一主轮廓局部消失或全图线宽趋同，均判定为线条不合格并重试。
10. 空白纸面必须接近 `paper.white #FBFDF8`；黄色可以作为面积明确的场景板或道具色，但边界必须清楚。若纸面、人物和背景同时出现统一黄褐偏色，判定为全局黄滤镜并重试。
11. 逐项对照 `references/style-reference-index.md` 检查颜色、线条、人物、背景、道具和 UI 六个维度；不得只以“整体像”作为通过依据。
12. 成图不得出现固定参考截图中的黑色边栏、视频字幕、播放器进度条、主页图标、原有文字、品牌名或水印。
13. 出现以下任一组合即判为“AI 商业插画感”并重试：半日漫眼睑或睫毛、皮肤明暗塑形、头发亮边或大量发丝、背景完整透视与高密度结构、道具完美几何、UI 严格居中等距、柔和渐变或发光阴影。不得以“整体好看”替代此项检查。
