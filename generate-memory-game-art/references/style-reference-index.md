## 强制使用规则

1. 把全部 `18` 张图片作为同一套画风证据；人物、背景、道具和 UI 不得分别套用互相冲突的通用插画风。
2. 只抽取颜色关系、线条重量、人物简化、背景组织、道具造型、平涂纹理和交互容器语言；不得复制具体角色、对白、地图、照片内容、关卡布局或镜头。
3. 原图中的黑色左右边栏、视频字幕、播放器进度条、返回/主页图标、原有文字、品牌名和水印属于截图干扰，禁止进入提示词或生成结果。
4. 人物参考照片只控制真人身份；本参考集只控制画风。真人的脸型、五官、发型、肤色、体型和服装不得被参考图角色覆盖。
5. 不得裁切、重绘、覆盖或合并 `style-images/` 中的原图；新增或替换参考图时必须同步更新本索引。
6. 图像工具单次最多接收 `5` 张参考图：无人像参考时选择最多 `5` 张风格图；有 `1` 张人物身份图时选择最多 `4` 张风格图；另有用户布局参考时选择最多 `3` 张风格图。选择结果必须覆盖人物线条、背景组织、道具和交互 UI 中与本任务直接相关的维度。
7. 风格优先级固定为：粗钴蓝人物外轮廓 > 极简五官与整体发块 > 平涂错版 > 低细节背景 > 不规则道具和 UI。不得为了“精致”加入眼睑睫毛、皮肤塑形、高光发丝、完整透视、完美几何或柔和渐变。
8. `STYLE.17 / STYLE.18` 是用户验收后的最终校准图，在与早期截图冲突时优先决定完成度、冷暖、线条重量、服装纹样密度和交互可读性；它们仍不得覆盖真人身份。
