# 生成留刻手绘互动叙事画面

把请求视为：

`数值化组件系统 + {{scene_description}} + 人物身份卡 + 交互状态 → 内部设计规格 → 短版高优先级生图提示词 → 图片`

`{{scene_description}}` 为必填变量；用户的自然语言描述就是变量值。不得把五个 MVP 场景或示例剧情写死。

## 执行流程

1. 提取人物、关系、动作、地点、时间、关键物件、数量、左右关系和叙事重点。
2. 完整读取 [references/style-reference-index.md](references/style-reference-index.md)，按索引查看 `references/style-images/` 中全部 `18` 张独立原图；不得用拼版、缩略图或文字总结替代原图检查。忽略原图中的黑色边栏、视频字幕、播放器元素、主页图标、原有文字和水印。
3. 完整读取 [references/approved-style-calibration.md](references/approved-style-calibration.md)，用 `STYLE.17 / STYLE.18` 校准已验收的最终完成度、人物简化、服装纹样、冷白配色和交互结构；它们仍只控制画风，不控制新任务的人物身份。
4. 完整读取 [references/component-system.md](references/component-system.md)，按 `360×640px` 基准画布建立内部设计规格，选择色彩模式、背景模式、人物、道具、画面组件和交互 UI 组件；内部规格保留完整数值，但不得把所有动画、坐标和重复禁令机械堆入生图提示词。
5. 完整读取 [references/prompt-contract.md](references/prompt-contract.md)，把内部设计规格压缩为短版高优先级生图提示词，只保留会改变静态像素结果的身份、构图、数量、核心尺寸、粗线、平涂、低细节和排除项。只提取参考集中的抽象设计规律，不复制具体角色、文字、地图、照片内容、关卡布局或镜头。
6. 有人物参考图时，先查看原图并完整读取 [references/character-identity.md](references/character-identity.md)；判断是“原照片转游戏插画”还是“新场景身份参考”，按照片分别建立 `CHARACTER.LEFT` 与 `CHARACTER.RIGHT` 身份卡。人物照片控制身份、人数、左右关系和可辨识特征，固定的 `18` 张风格参考图只控制画风，两者不得混用。
7. 把人物身份卡完整写入提示词；不得只写“参考照片人物”“保持一致”或只依赖服装颜色。若参考图无法清楚区分两人，先请用户补充清晰照片。
8. 若用户未指定画幅，使用 `360×640px` 逻辑画布、`1080×1920px` 输出；指定画幅时按同一比例换算全部尺寸。
9. 先输出 `### 完整生图提示词`，在代码块中展示补全后的短版提示词；目标长度为中文 `900–1800` 字，包括人物身份卡、静态构图、核心组件尺寸、粗线平涂规则和针对性排除项。不得为凑全参数重复同义句。
10. 展示后立即把代码块中的提示词原样用于图像生成。每次仍须逐张查看全部 `18` 张固定原图，但按 [references/style-reference-index.md](references/style-reference-index.md) 选择最相关的独立原图直接输入：无人像参考时最多 `5` 张；有 `1` 张人物身份参考时最多 `4` 张风格图；另有用户布局参考时相应减为 `3` 张。聊天优先提交 `STYLE.18`，吃饭优先提交 `STYLE.17`；所有原图永久独立保留，不合并、不删除。只有用户明确说“只要提示词”“暂不生图”或“确认后生成”时才停止。
11. 出图后按场景、人物身份、背景中性度、交互组件、粗线和平涂低细节门槛检查。出现全局黄滤镜、人物外轮廓偏细、五官发丝过细、半日漫脸、皮肤或头发柔和渲染、背景透视过完整、道具/UI 过度规整，或任一人物不可辨认、特征交换、变成通用卡通脸时，必须判为失败；先展示只针对失败项修订的短版提示词，再自动重试一次。

## 内容边界

- 默认只生成温暖、心动、亲密、轻松、共同回忆等正向情侣叙事。
- 用户未要求时，不生成分手、冷战、压抑、恐怖、受伤或悲剧情绪。
- 复用抽象设计规律，不复制 Florence 的角色、镜头、关卡布局、对白、UI 文案或标志。
- 需要文字时只预留文字容器；图片内不生成字幕、说明文字、水印或品牌标志。
- 人物参考图只用于人物身份、人数、左右关系以及适用模式下的姿态、表情和亲密关系；固定的 `18` 张风格参考图只用于画风。不得用风格参考覆盖真人身份，也不得把真人照片的摄影背景带入新场景。
- `STYLE.17 / STYLE.18` 是已验收的完成度基准，不得复用其中人物长相、服装身份或具体食物组合；只复用线条、颜色、纹样转译、背景密度和交互层级。
- 不生成参考截图中的黑色边栏、视频字幕、播放器进度条、主页图标、原有文字、品牌名或水印。
- 不改变人物年龄，不换脸，不把两人过度美化成相似的通用卡通脸；不得交换两人的发型、肤色、服装、配饰或面部特征。
- 不生成“干净商业 AI 插画”外观：禁止半日漫精致脸、眼睑与睫毛渲染、皮肤明暗塑形、逐束高光发丝、顺滑手部建模、完整室内透视、完美几何道具、严格居中等距 UI 和柔和渐变阴影。
- 优先保留参考集中的笨拙手绘感：粗钴蓝轮廓、少量内部线、平涂色块、轻微错版、局部干刷缺口、不完全对称的边框和道具。

## 数值质量门槛

- 基准画布必须为 `360×640px`，高清输出必须为 `1080×1920px`，倍率为 `3×`。
- 以 `STYLE.17 / STYLE.18` 为描边粗细的最高优先级标尺。逻辑画布线宽固定为：人物外轮廓 `4.8px ± 0.4px`、内部结构线 `2.3px ± 0.2px`、食物/道具/普通控件 `3.8px ± 0.3px`、大 UI 外框与主场景分隔线 `5.2px ± 0.4px`、提示虚线 `2.8px ± 0.2px`；高清输出分别为 `14.4px ± 1.2px`、`6.9px ± 0.6px`、`11.4px ± 0.9px`、`15.6px ± 1.2px`、`8.4px ± 0.6px`。提示词必须同时写出两套数值，不得再把场景、道具和 UI 合并为一档细线。
- 人物外轮廓与内部线的视觉粗细比必须为 `1.9:1–2.3:1`；脸、下颌、颈肩、手臂、手掌、头发外缘与眼镜外框都使用人物外轮廓档。大 UI 外框和主分隔线可与人物外轮廓等重或粗 `5%–15%`，普通背景结构线不得抢重；线条路径抖动必须为逻辑画布 `0.8–1.6px`。
- 成年人物必须为 `6.0–7.0` 头身、肩宽 `1.5–2.2` 个头宽；眼睛不得超过 `3×5px`，不得出现虹膜、高光和日漫睫毛。
- 有人物参考图且人物辨识是核心目标时，逻辑画布中的可见脸高不得小于 `40px`；优先采用半身或中近景，不能通过缩小面部牺牲身份辨识度。
- 每位人物必须匹配发型轮廓、发色、脸型和所有显著标记，并至少匹配眉眼走向、鼻部轮廓、嘴形/笑容、耳朵轮廓、肤色关系、体型、服装款式与主色中的 `4` 项；服装相同不能替代面部身份一致。
- 判定头发长度时，以从头顶连续到最远可见发梢的整体剪影为准；脸侧短层次、刘海或遮挡不得覆盖“长发/短发”结论。
- 真人服装有小花、圆点等纹样时，只保留底色、纹样类型与主色关系：默认 `8–18` 个不规则手绘图案、覆盖服装 `10%–25%`，被头发、手臂、道具和衣服边缘自然截断；等距平铺、同尺寸重复或跨遮挡连续均判为失败。
- 人物人数和左右对应必须与参考图一致；除非用户明确指定新场景动作，否则原照片转插画时还必须保持姿态、表情和亲密关系。
- 每张图必须从 `BACKGROUND.PAPER_STAGE / BACKGROUND.COLOR_PANEL / BACKGROUND.FULL_SCENE / BACKGROUND.COLLAGE_MAP` 中选择一个背景模式，并从 `PALETTE.PAPER_STAGE / PALETTE.COLOR_PANEL / PALETTE.FULL_SCENE / PALETTE.MONO_MEMORY` 中选择一个色彩模式；不得把同一留白比例硬套到所有场景。
- 空白纸面使用 `#FBFDF8`；米白 `#FBEFC8`、浅蓝 `#D8EFF5` 只作为局部纸面或面板。黄色 `#FBB303` 可以占全画布 `5%–25%`，或占单个彩色场景板 `35%–65%`，但必须具有清楚边界，不得形成全局黄滤镜。
- 普通背景只保留 `2–3` 个地点符号，细节占全画布 `5%–15%`；局部叙事场景板内默认不超过 `12%–25%`；只有地图或记忆拼贴模式可达 `45%–70%`。关键交互道具作为焦点时占画布 `15%–35%`。
- 在 `25%` 缩略预览下，人物主外轮廓、大 UI 外框、食物与主要道具轮廓都必须连续清楚；人物外轮廓约为五官、发丝与衣褶线的 `2` 倍，大 UI 外框不得细于人物轮廓，食物/普通控件不得退化为内部线。人物脸部不得依靠眼睑、睫毛、皮肤阴影或发丝高光成立。空白纸面必须保持中性，局部黄色场景板必须边界清楚。任一项失败都必须按失败项自动重试一次。
- 所有可点击、拖拽或长按区域不得小于 `48×48px`；组件之间的最小间距为 `12px`。
- 不得出现写实 3D、厚涂、电影光效、半日漫精致脸、日漫大眼、Q 版比例、机械矢量直线、柔和渐变塑形、完整摄影透视、多余肢体、乱码或无关文字。
